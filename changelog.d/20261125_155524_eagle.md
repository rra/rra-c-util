### Bug fixes

- Add `-Wno-c++-keyword` and `-Wno-implicit-void-ptr-cast` to the default Clang warning flags in `RRA_PROG_CC_WARNING_FLAGS`. These flags do not apply to C.
- Add `-Wno-pre-c11-compat` and `-Wno-pre-c23-compat` to the default Clang warning flags in `RRA_PROG_CC_WARNING_FLAGS`. These warnings have false positives with `bool` and glibc headers.
